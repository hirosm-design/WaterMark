# コンテンツポリシー（おセンシの時間 / X SNS運用チーム 共通ガード）

このチームが生成する全てのプロンプト・投稿文は、以下のガードレール内で作成する。
毎週テーマが変わっても、この方針は固定とする。

## 必ず守ること

- **キャラクターは成人のみ**。イラスト・実写いずれのプロンプトにも
  「adult / 20s-30s / 成人」を明記し、幼形・低身長・童顔を強調する表現は避ける。
- **実写（フォトリアル）プロンプトは、特定の実在人物をモデルにしない。**
  架空のオリジナルAIモデル/キャラクターとして扱う（本ドキュメントの
  「シリーズ持ちキャラ」を参照）。実在の有名人・個人を指定するリクエストは
  受け付けない（同意確認ができないため、本人希望であっても不可）。
- **露出・表現の上限は「際どい構図＋際どい衣装」まで。**
  水着・浴衣の着崩れ・ランジェリー・後ろ姿・上目遣いなど「色気はあるが
  露出は抑えめ」の範囲に留める。性器・乳首等の露出、性行為・性的示唆の
  直接描写は一切生成しない。
- ネガティブプロンプトに年齢・露出関連の除外ワードを必ず含める
  （各プロンプトテンプレート参照）。

## 週次運用の流れ

1. **リサーチ班** (`agents/researcher.md`) が、依頼者から聞いた「今日のテーマ」と
   X上の話題・関連イベントを整理する。
2. **ディレクター** (`agents/director.md`) が週替わりメインテーマを確定する。
3. **イラストプロンプト班** (`agents/illustration-prompt-writer.md`) が
   イラスト生成AI向けプロンプトを作成する。
4. **実写プロンプト班** (`agents/photoreal-prompt-writer.md`) が
   フォトリアル生成AI向けプロンプトを作成する（架空モデルのみ）。
5. **コピー班** (`agents/copywriter.md`) がX投稿文・ハッシュタグを作成する。

成果物は `posts/YYYY-MM-DD-volN-テーマ名.md` として保存する。
