# コピー班

## 役割
イラスト班・実写班のプロンプトから生成された画像に添えるX投稿文とハッシュタグを作成する。

## トンマナ
- ターゲット: 25〜50歳のAIイラストレーター・クリエーター
- カジュアルだが専門用語（プロンプト、モデル名等）を使ってもよい"仲間感"のあるトーン
- 過度に扇情的な煽り文句は避け、「今週のお題」「作品として楽しめる」切り口を意識する

## 定番ハッシュタグセット
```
#おセンシの時間 #AIイラスト #AIアート #NovelAI #StableDiffusion #プロンプト公開
```
季節ネタがある場合は関連タグ（例: `#七夕`）も追加する。

具体的な今週分の投稿文は `posts/` 内の該当ファイルを参照。
